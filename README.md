# 용과 같이 켄잔! 한글패치
**대상 게임:** 용과 같이 켄잔! (龍が如く 見参！ / Ryū ga Gotoku Kenzan!)  
**지원 버전:** PlayStation 3 일본/아시아판 **BLJM60064**  

《용과 같이 켄잔!》의 게임 내 텍스트와 화면 요소를 한국어로 즐길 수 있도록 제작한 비공식 한글패치입니다.

## 한글화 적용 내용

- 메인 스토리 및 각종 이벤트의 대사와 영상 자막
- 대화창, 메뉴, 시스템 안내, 저장·장비·전투 관련 UI 문구
- 지역명, 장소명, 이동 안내 등 지명 관련 텍스트
- 아이템·기술·게임 내 설명을 비롯한 주요 텍스트
- 한국어 글꼴 및 텍스트가 포함된 일부 게임 UI 이미지

> **v0.1 안내:** 일부 일본어 문구가 남아 있거나 화면 표시가 매끄럽지 않을 수 있습니다. 특히 세이브 목록의 장 제목이 실제 진행 상황과 다르게 표시되는 문제는 아직 완전히 검증되지 않았습니다.

## 한글패치 적용 방법

**준비물**

- 정품에서 직접 추출한 《용과 같이 켄잔!》 일본/아시아판 **BLJM60064** 게임 폴더
- Windows PC
- 여유 저장 공간 **23GiB 이상**
- GitHub Releases에서 받은 배포용 파일 **`켄잔_한글패치_단일EXE.exe`**

**설치 순서**

1. `켄잔_한글패치_단일EXE.exe`를 실행합니다.
2. **[게임 폴더 선택 후 적용/업데이트]** 버튼을 누릅니다.
3. `PS3_GAME` 폴더와 `PS3_DISC.SFB` 파일이 함께 있는 **순정 게임의 최상위 폴더**를 선택합니다.

   ```text
   원본 게임 폴더/
   ├─ PS3_DISC.SFB
   └─ PS3_GAME/
      ├─ PARAM.SFO
      └─ USRDIR/
         └─ EBOOT.BIN
   ```

4. 패치가 완료되면 원본 게임 폴더와 같은 위치에 **`Kenzan_KO_BLJM60064`** 폴더가 생성됩니다.
5. RPCS3에서 새로 생성된 한글판 게임 폴더를 등록하여 실행합니다.

원본 게임 폴더는 그대로 보존하며, 패치는 별도 폴더에 적용됩니다. 번역 CSV, 이미지, 폰트 파일이나 Python을 따로 설치할 필요는 없습니다.

**업데이트 및 복원:** 같은 위치에 지원되는 기존 한글판 출력 폴더가 있으면 패치툴에서 업데이트할 수 있습니다. **[원본 복원]** 버튼은 한글판 **출력 폴더**를 순정 데이터로 복원하는 기능이며, 원본 게임 자체를 변경하는 기능이 아닙니다.

## 이용 전 확인 사항

- **PS3 실기(CFW/HEN)에서는 아직 동작을 검증하지 않았습니다.** 실기에서 정상 실행된다고 보장할 수 없으며, 순정 PS3 시스템 소프트웨어(OFW)는 지원하지 않습니다.
- RPCS3에서도 게임 전체 구간에 대한 완전한 플레이 검증이 끝난 상태는 아닙니다.
- **반드시 정품 게임을 보유하고, 본인이 소유한 정품에서 적법하게 추출한 게임 파일을 사용해 주세요.**
- 이 배포물에는 게임 본편이나 원본 게임 데이터가 포함되어 있지 않습니다. 불법 복제 게임의 다운로드·공유를 지원하지 않습니다.
- 본 한글패치는 비공식 팬 제작물이며, 원작의 권리자와는 관계가 없습니다.
